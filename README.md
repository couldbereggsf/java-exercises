## 🚀 How to Compile & Run (Terminal)
Since Java is a compiled language, I follow the Compile-then-Execute workflow.

Standard Procedure:
Navigate to the root source folder (e.g., java-exercises):

**Bash**
```
cd java-exercises
```

**Compile the source file:**

Bash
```
javac com/amigoscode/Exercise.java
```
**Run the bytecode:**

**Bash**
```
java com.amigoscode.Exercise
```
**Note:** Always run the java command from the root of the package structure using the dot notation (com.package.Class) rather than the file path.

### 📝 Learning Log & Concepts
**1. Variables and Data Types**

   * **Primitive Types:** int for whole numbers, double for decimals, boolean for logic.

* **Reference Types:** String, Arrays, and custom Classes.

**2. Comparison Logic**
   * **Assignment (=)**: Sets a value.

* **Comparison (==)**: Checks for equality.

**Boolean Results:** All comparisons (>, <, !=) result in a boolean type (true/false).

### 3. Package Management
   Java uses packages (e.g., package com.amigoscode;) to prevent naming conflicts.

**Golden Rule:** The folder structure on your computer must match the package declaration in the code.

### 🏗 Assignment Workflow
When starting a new assignment, I follow the **IPO Model:**

* **Input:** Define variables and gather data.

* **Process:** Apply logic, math, or comparisons.

**Output:** Use System.out.println() to display results.
